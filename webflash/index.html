Stock Clock Web Flasher

在浏览器里给 M5StickS3 烧录 Stock Clock 固件（类似 Bruce Flasher）。 需要 Chrome / Edge，并允许串口权限。

1. 进下载模式

  • USB 连接电脑
  • 若识别不到：关机后按住 BtnA 再插 USB
  • 或短按侧边复位进入下载

2. 烧录到设备

点击下方按钮 → 选择串口 → 等待完成并复位。

DOWNLOAD FIRMWARE .BIN

本页必须通过 HTTPS / localhost 打开；直接打开本地 HTML 文件通常无法连接串口。

说明

  • 固件由 GitHub Actions 从 main 自动构建并发布
  • 合并镜像：bootloader + 分区表 + app，偏移 0x0
  • 源码：github.com/1yzz/esp32_stock_clock
